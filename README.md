# 世界時鐘

翻頁鐘風格的世界時鐘網頁，列出各地的日期與時、分、秒。

- 第一張卡片固定是瀏覽器所在時區的本地時間
- 右上角 ＋ 可搜尋並新增約 350 個世界主要城市（中英文皆可），同一國家的不同時區分開列出，例如巴西的瑪瑙斯與里約、墨西哥的坎昆與墨西哥城
- 搜尋國家時，也會列出該國在 tzdata 裡的其他所有時區
- 卡片可移除（5 秒內可復原），也可以拖曳握把調整順序
- 清單與順序存在瀏覽器的 localStorage
- 每張卡片用一個小圖示顯示當地此刻的天空：太陽在天上時是太陽，日出或日落前後一小時是日出或日落；夜晚是月亮（畫出當天月相），月出或月落前後一小時是月出或月落；卡片在太陽升起時是亮色、日落後是暗色
- 右上角可切換中文／英文介面（國名、城市、日期、提示文字一起切換），選擇會記在瀏覽器裡
- 支援手機、桌機，以及淺色／深色主題

城市與時區對照依據 IANA tzdata（zone.tab），城市座標來自 GeoNames，日月時間用 [SunCalc](https://github.com/mourner/suncalc) 計算。

單一檔案 `index.html`，不需要建置，直接用 GitHub Pages 發布即可。


## 晴天旅遊世界時鐘（Sunday Tour）

`sundaytour-clock.html` 是晴天旅遊專用的版本，預設只顯示本地時間。

- 右上角 ＋ 可搜尋新增城市
- 圖片按鈕可一鍵匯入地點：上傳行程截圖（可多張、拖曳或直接貼上截圖），或貼上行程文字，依出現順序加入時鐘
- 圖片文字辨識用 [Tesseract.js](https://github.com/naptha/tesseract.js) 在瀏覽器內完成，圖片不會上傳；中英文字庫放在 `tessdata/`（內容是 gzip 的 traineddata，副檔名用 `.wasm`）
- 同一國家裡，未來一年 UTC 時差與夏令時間規則完全相同的地點合併成一個時鐘；跨多個時區的國家依各地點歸類，例如智利分成聖地牙哥、蓬塔阿雷納斯（百內國家公園）、復活節島
- 只認得內建資料中的地名：約 350 個城市、tzdata 時區名稱，以及常見旅遊景點與不同譯名

`sundaytour-clock.html` 要和 `tessdata/`、`examples/` 資料夾放在同一層；`examples/itinerary-example.jpg` 是匯入視窗裡「範例圖」連結顯示的截圖。
